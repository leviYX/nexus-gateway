# HTTP 服务搭建

目标：基于 Atlas 的 Maven 配置，建立单模块、可独立运行的 Netty HTTP 服务。

设计：Java 25、Netty 4.2.21.Final、Jackson 2.20.0；使用 NIO transport，便于学习事件循环。
启动入口负责配置与关闭钩子，服务类负责监听与资源释放，初始化器组装 HTTP pipeline，
处理器负责内置 JSON 接口，静态注册表描述本地路由。默认监听 0.0.0.0:8080，聚合请求体上限 1 MiB。

实施与验证：

1. 添加 POM、Maven Wrapper 和真实 HTTP 集成测试，确认缺少服务实现时构建失败。
2. 实现配置验证、服务生命周期、HTTP 编解码与内置路由；验证查询参数、HEAD、404、405、413、Keep-Alive 和端口释放。
3. 构建可执行 JAR，启动后使用 curl 验证接口，发送终止信号验证退出。
4. 根据实际实现更新 README 的状态、启动方式、配置与后续路线。

边界：本阶段只有本地接口；上游转发、过滤器、连接池、限流和其他协议后续逐步实现。
